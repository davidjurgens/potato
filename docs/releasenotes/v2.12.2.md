# Release Notes: v2.12.2 — Security Fixes, Per-Annotator Chats and Paradata Phases

This release fixes a stored cross-site scripting bug present in every 2.x
release and escapes untrusted values on the admin, adjudication and
several display pages. It also stores agent chats per annotator, fixes image
export sizes, landmark drift and the deep-zoom layout, and adds a `phases`
key for the paradata trackers. Upgrade every running study.

```bash
pip install --upgrade potato-annotation
```

## Security

- **Item data could run script on the annotation page.** Every item's
  fields are written into the page as JSON inside a `<script>` element.
  An item whose text contained a closing script tag ended that element
  early, and whatever followed ran in each annotator's browser. The HTML
  sanitizer did not see this path. The JSON is now written with `<`, `>` and
  `&` escaped. Every release from 2.0.0rc2 on is affected.
- **Untrusted values are escaped on the admin and adjudication pages.**
  Usernames, crowd participant IDs from URL parameters, annotators' free
  text and item text were inserted into the admin dashboard and the
  adjudication forms without escaping. The admin page also holds the admin
  API key, so script there could read it. The Questions tab now shows each
  scheme's name and description as text.
- **More pages escape item, annotator and model text:** the code, PDF,
  spreadsheet, document and protein displays; the embedding view, corpus
  map, entity linking, multi-document events, codebook and search; the solo
  mode, psychometrics, truth-serum, boundary and think-aloud dashboards; the
  web-agent and live-agent viewers; and the extractive QA restore.
- **The HTML sanitizer refuses `java<TAB>script:` links.** A tab, line feed
  or carriage return inside the scheme got past the link check on sanitized
  instance text.
- **The web-agent proxy and SVG media are sandboxed.** Pages fetched through
  the web-agent proxy, and SVG files served through `/media/proxy`, now get a
  sandboxing Content-Security-Policy, so they cannot run script on Potato's
  origin. Proxied pages load their resources with a signed, proxy-only token
  that expires after 12 hours.
- **MTurk's submit address must be an MTurk host.** `turkSubmitTo` comes from
  a URL parameter and becomes the done page's form action. Only
  `https://www.mturk.com` and `https://workersandbox.mturk.com` are accepted
  now; any other value shows no submit form.

## Agent chat storage

Finishing an `interactive_chat` conversation wrote it into the item that
every annotator shares. A second annotator on that item saw the first
annotator's conversation in place of their own chat panel, and the
conversation was lost on restart and missing from exports. Conversations
are now stored per annotator and item in `<task_dir>/project.sqlite`. They
survive a restart and are exported: JSONL records carry an `agent_chat`
object, and CSV and TSV exports write an `agent_chat_turns` file with one row
per turn. See [Interactive chat](../agent-evaluation/interactive_chat.md).

## New features

- **Paradata trackers can be limited to some phases.** `authenticity`,
  `keystroke_logging`, `annotation_telemetry` and `interaction_tracking`
  accept `phases`, a list of phase types or `phases.order` names. A study
  that needs consent before it records paradata can start recording after
  the consent page. Without the key nothing changes
  ([#177](https://github.com/davidjurgens/potato/issues/177),
  [#178](https://github.com/davidjurgens/potato/pull/178), by @Eyecatch3r).
- **jsPsych pages can report answers to page rules.** `answers: [agree]` on
  a `type: jspsych` page makes the timeline's `agree` value available to
  `show_when` and `exit_when`, so a consent page written in jsPsych can
  screen out a participant who declines.

## Bug fixes

- **Image exports used another image's size.** The Cityscapes, CVAT, Darwin,
  KITTI, DAVIS, MOT and LabelMe exports sized every image from the record of
  the image annotated last whenever an image's size came only from its own
  mask. Coordinates were then scaled to the wrong frame.
- **Landmarks drifted on every save.** A landmark's stored point moved right
  by about half its label's width each time it was saved and restored, and a
  new landmark was drawn a few pixels from the click.
- **Deep-zoom slides were squashed and cut off.** The drawing canvas kept a
  fallback height that differed from the slide viewer's, so the slide was
  squashed vertically and shapes drew below the tissue they outline. The home
  view also fitted the slide's width and cut off its bottom. It now fits the
  whole slide and re-fits on resize until the annotator zooms or pans.
- **Malformed interaction batches changed saved data.** A
  `/api/track_interactions` batch with a bad entry could record part of the
  batch and then fail with a server error. The whole batch is now checked
  first, and a bad one gets a 400 before anything is recorded.
  Scroll depth is kept between 0 and 100
  ([#179](https://github.com/davidjurgens/potato/pull/179), by
  @abaichuan1017).
- **Batch participants saw the whole pool in their progress count.** With
  `batch_assignment`, the counter included items from other groups. It now
  counts only items the participant can be given
  ([#180](https://github.com/davidjurgens/potato/pull/180), by
  @abaichuan1017).
- **A participant stuck in the login phase could not get back in.** A saved
  state left at the login phase sent the participant round a redirect loop.
  Signing in now moves it on to the first configured page
  ([#181](https://github.com/davidjurgens/potato/pull/181), by
  @abaichuan1017).
- **Autosave loaded active learning when it was off.** The first save
  imported the active-learning module and scikit-learn even when
  `active_learning` was absent or disabled
  ([#182](https://github.com/davidjurgens/potato/pull/182), by
  @abaichuan1017).
- **`potato validate` names `base_html_template`.** Nothing reads the key;
  `potato validate` now warns about it the way it warns about `header_file`.
- **The `runtime` export's description** named runtimes Potato does not have.
  It now lists jsPsych, the headphone check and external tasks.
